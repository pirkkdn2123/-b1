# 별빛 소환대: 마지막 성채

오리지널 2D 소환·합성 디펜스 게임입니다. 외부 이미지·음원 파일 없이 HTML Canvas와 CSS로 화면을 그리므로, `index.html` 하나만 정적 웹 호스팅에 올리면 됩니다.

## 시작 방법

1. `index.html`을 웹 호스팅의 최상위 폴더에 올립니다.
2. 공개된 HTTPS 주소를 휴대폰이나 PC 브라우저에서 엽니다.
3. 시작 화면에서 **성채 방어 시작**을 누릅니다.
4. 게임이 시작되면 매초 3골드가 지급되고, 몬스터가 시간에 맞춰 나타납니다.

## 조작 방법

- **랜덤 소환 · 15G**: 검사, 궁수, 마도사, 수호자 중 한 명을 무작위로 소환합니다.
- **영웅 배치 변경**: 배치된 영웅을 한 번 누른 뒤 다른 칸을 누르면 두 영웅의 위치가 바뀝니다.
- **집중 공격**: 전장 안의 몬스터를 직접 누르면 영웅들이 그 몬스터를 우선 공격합니다.
- **집중 명령**: 집중 공격 대상을 해제합니다.
- **Ⅱ 일시정지**: 게임 시간과 골드 지급, 전투를 멈춥니다. 계속하기를 누르면 재개됩니다.
- **도움말**: 언제든 게임 설명을 다시 확인할 수 있습니다.

## 골드와 합성

- 시작 버튼을 누른 뒤 **1초마다 3골드**를 받습니다.
- 몬스터를 처치하면 추가 골드를 받습니다.
- 랜덤 소환 1회 비용은 **15골드**입니다.
- 배치 칸은 **12칸**입니다.
- 같은 종류·같은 등급의 영웅을 모으면 자동 합성됩니다.
  - 일반 3명 → 희귀 1명
  - 희귀 4명 → 레어 1명
  - 레어 4명 → 레전더리 1명
- 레전더리를 만들면 화면 중앙에 **“레전더리를 뽑았습니다!”** 연출이 표시됩니다.

## 영웅 4종

| 영웅 | 역할 |
|---|---|
| 검사 | 가까운 적에게 강한 검 공격 |
| 궁수 | 빠른 원거리 공격 |
| 마도사 | 마법탄과 주변 적에게 퍼지는 범위 피해 |
| 수호자 | 묵직한 공격과 적 둔화 효과 |

각 등급으로 성장할수록 공격력이 올라가고 외형의 장식과 빛 효과가 강화됩니다. 레전더리는 고유한 빛의 오라와 파티클을 가집니다.

## 몬스터 출현 시간

- 시작 후 **10초**: 고블린 정찰병
- 시작 후 **25초**: 떠도는 해골이 합류
- 시작 후 **40초**: 정예 도적이 합류
- 시작 후 **55초**: 성채 파괴자가 합류
- 55초 이후에는 강화된 성채 파괴자가 약 5.3초 간격으로 계속 등장하며, 시간이 지날수록 체력과 이동 속도가 높아집니다.

몬스터가 왼쪽 성문에 도달할 때마다 성채 내구도가 1 줄어듭니다. 내구도 15가 모두 소진되면 게임이 종료됩니다. 다시 도전 버튼으로 새 판을 시작할 수 있습니다.

## 모바일 최적화

- Canvas 2D 단일 렌더 루프를 사용합니다.
- 화면 픽셀 비율을 최대 1.55로 제한합니다.
- 동시에 표시하는 적과 파티클 수를 제한합니다.
- 별도 이미지·3D 엔진·외부 게임 에셋을 내려받지 않습니다.
- 현재 판의 골드와 영웅 배치는 페이지 새로고침 시 초기화됩니다.

## GitHub Pages 배포

1. GitHub 저장소에 `index.html`을 업로드합니다.
2. 저장소 Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
3. 생성된 HTTPS 주소를 NFC 카드에 URL로 기록할 수 있습니다.

Netlify 등 다른 정적 웹 호스팅에도 `index.html`을 그대로 올릴 수 있습니다.
